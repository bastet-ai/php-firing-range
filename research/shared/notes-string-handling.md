The progress marker value is read into an allocated body buffer with an explicit `size_t` length and passed to the callback (`src/php-src-83/main/rfc1867.c:839-870`). Session concatenates that exact length onto the fixed prefix using `smart_str_appendl`; embedded NULs therefore remain part of the Zend string/hash key (`src/php-src-83/ext/session/session.c:3142-3146`). This is not direct corruption by itself, but creates C-string/Zend-string semantic skew for serializers, logging, or consumers. Defensive detection: log marker value length/hash, not `%s`; cap form-field lengths at the edge.

The multipart SID field is likewise copied with `ZVAL_STRINGL` and later into `PS(id)` with its explicit length (`src/php-src-83/ext/session/session.c:3139-3141,3185-3186`). Cookie/GET SID is copied as a zval string (`src/php-src-83/ext/session/session.c:3009-3013`). The normal `session_start` forbidden-character gate at `src/php-src-83/ext/session/session.c:1625-1627` is bypassed by this upload initialization path, although the default files handler independently rejects illegal keys (`src/php-src-83/ext/session/mod_files.c:168-175`). Non-files/user save handlers therefore deserve separate scrutiny for binary/oversized SIDs.

File field name and client filename are copied with NUL-terminated APIs into session metadata without content sanitization (`src/php-src-83/ext/session/session.c:3195-3200`). They originate in parsed Content-Disposition parameters and are handed to FILE_START (`src/php-src-83/main/rfc1867.c:771-837,957-963`). The progress record stores the full client filename here, whereas normal `$_FILES[name]` later applies basename (`src/php-src-83/main/rfc1867.c:1124-1144`). Values are serialization-safe length-tagged strings, but are untrusted persistent metadata and may create downstream log/UI/path misuse; no direct memory corruption found from content alone.

The temporary filename copied at FILE_END is server-generated, not client-controlled (`src/php-src-83/main/rfc1867.c:996-1000,1076-1082`; `src/php-src-83/ext/session/session.c:3235-3237`). Numeric metadata derives from Content-Length/read counters and time (`src/php-src-83/ext/session/session.c:3115-3117,3177-3183,3203-3205`).
